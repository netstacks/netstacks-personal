# Contributing

Thanks for your interest in NetStacks.

This repository is a **read-only mirror**: it is published automatically from
NetStacks' development repository, so pull requests opened here cannot be merged
(they are closed automatically with a pointer back to this page).

How to help:

- **Bug reports.** Open an [issue](https://github.com/netstacks/netstacks-personal/issues)
  with the NetStacks version (Settings → About), your OS, what you did, what you
  expected, and what happened. A minimal reproduction helps more than anything.
- **Feature requests.** Open an issue describing the problem you are trying to
  solve, not only the solution you have in mind.
- **Security issues.** Do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **Patches.** If you have a fix, describe it in an issue (a diff or a link to
  your fork is welcome). Changes are applied upstream and arrive here with the
  next sync, credited in the commit message.
